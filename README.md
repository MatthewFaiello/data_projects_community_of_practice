# Data Projects Community of Practice

Course materials for the DDOE community of practice, facilitated by Matt Faiello. Sessions use practical R projects to discuss how work is organized, recorded and shared.

## Sessions

| Session | Topic | Main materials |
| --- | --- | --- |
| [Session 1](sessions/session-01/README.md) | R projects and GitHub using the FAFSA Shiny app | [Slide deck](sessions/session-01/slides.pptx) · [Companion document](sessions/session-01/companion.docx) · [Read the companion online](sessions/session-01/companion.md) |

Each session has a slide deck and a companion document. Supporting code, prompts and procedures are linked from the session page.

## Getting started with Session 1

Open the [Session 1 page](sessions/session-01/README.md). Download the FAFSA starter ZIP from that page and extract it outside this course repository and any other Git repository. The starter becomes your own practice project. Keep the companion open during the meeting.

The course repository holds shared learning materials. Participants create their own private GitHub repositories for the app exercise.

## Help from ChatGPT

Use the [Session 1 context](sessions/session-01/prompts/CHATGPT_CONTEXT.md), the relevant companion section and your actual command output. [Copyable prompts](sessions/session-01/prompts/README.md) help explain the project, inspect Git setup and troubleshoot one step at a time.

## Updating materials

The Markdown companion is the editable text source for the Word document. Update both formats together. Keep slide text and speaker notes aligned with [slides.md](sessions/session-01/slides.md), and record substantive changes in [CHANGELOG.md](CHANGELOG.md).
