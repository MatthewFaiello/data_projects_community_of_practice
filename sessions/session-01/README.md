# Session 1 R projects and GitHub

Use the FAFSA Shiny app to explore project directories, RStudio Projects, relative paths and GitHub version control. The meeting closes with a high-level preview of the supplied DDOE GitLab deployment handoff.

## Practice app

[Download the FAFSA starter ZIP](https://github.com/MatthewFaiello/data_projects_community_of_practice/raw/refs/heads/main/sessions/session-01/practice/fafsa_template.zip).

Extract this ZIP to a local folder outside the course repository and any other Git repository. Open `fafsa_template/fafsa_template.Rproj` in the extracted files. Do the Git exercise in that app folder. Downloading the starter does not require cloning or forking this course repository.

The starter has no inherited Git history or remote. Its fixed, summarized snapshot opens at school year 2026. Year 2027 intentionally has no receipt months. It is a training example rather than current reporting.

## Before the meeting

Use page 1 of the companion. Confirm that R, RStudio and Git work, run the practice app, and create an empty private GitHub repository for your exercise. The [setup reference](resources/getting-ready.md) has additional checks.

## Meeting flow

| Minutes | Focus |
| --- | --- |
| 0 to 10 | FAFSA demonstration and colleague handoff scenario |
| 10 to 25 | Open the project and explain its files and input path |
| 25 to 35 | Git concepts and hosting roles |
| 35 to 80 | Connect GitHub and verify a small change locally and online |
| 80 to 90 | GitLab preview and next practice |
